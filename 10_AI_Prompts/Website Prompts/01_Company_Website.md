# Company Website Prompt

请你担任资深品牌策略师、UX/UI 设计师、网站信息架构师与 SEO 顾问。根据以下客户资料，为一个专业、可信、以业务成果为导向的公司官网制定完整的网站方案。请保留清晰的层级、合理的用户路径与可执行的内容建议；所有方括号内容均为待替换信息。

## 1. 项目背景

- 公司名称：[公司名称]
- 行业：[行业]
- 核心业务：[主营业务]
- 公司规模与成立时间：[公司规模 / 成立时间]
- 服务地区：[国家、城市或全球市场]
- 品牌优势：[核心优势、资质、经验或差异化]
- 品牌故事：[品牌背景]
- 竞争对手或参考网站：[链接]

请总结行业背景、品牌定位、竞争环境，以及网站需要解决的核心问题。

## 2. 目标客户

- 客户类型：[企业客户 / 个人客户 / 机构客户]
- 行业或职业：[客户行业]
- 地区：[目标国家或地区]
- 年龄与消费能力：[画像]
- 决策角色：[决策人 / 采购人 / 使用者]
- 主要痛点：[痛点]
- 选择服务时最看重的因素：[价格 / 信任 / 专业 / 速度等]

请建立 1–3 个主要用户画像，并说明他们访问网站时的动机与顾虑。

## 3. 网站目标

- 首要目标：[展示品牌 / 获取询盘 / 销售服务 / 招聘等]
- 次要目标：[目标]
- 主要转化动作：[填写表单 / WhatsApp / 电话 / 预约咨询]
- 成功指标：[询盘数量、转化率、流量或其他 KPI]

请将业务目标转化为网站策略、页面重点与明确的 CTA。

## 4. 网站结构

请规划清晰的网站 Sitemap，至少考虑：

- 首页
- 关于我们
- 服务 / 解决方案
- 行业或应用场景
- 案例 / 客户见证
- 资质 / 团队
- 博客 / 资源中心
- 联系我们

请为每个页面说明页面目标、核心内容、推荐模块、用户 CTA，并建议首页内容顺序与导航结构。

## 5. 设计风格

- 品牌气质：[专业 / 稳重 / 创新 / 国际化 / 亲和]
- 喜欢的网站：[链接]
- 不喜欢的风格：[描述]
- 视觉关键词：[关键词]
- 图片方向：[实拍 / 产品图 / 3D / 插画 / 数据图表]

请提出适合行业与目标客户的 UI 方向，包括版式、留白、视觉层级、图片处理、图标与动效原则，并确保桌面端与移动端一致。

## 6. 颜色建议

请基于品牌定位提供 2–3 套配色方案。每套方案需包含：

- 主色及 HEX 色值
- 辅助色及 HEX 色值
- CTA 强调色及 HEX 色值
- 背景色与文字色
- 颜色使用比例与可读性建议

优先考虑品牌识别、行业联想、无障碍对比度与转化场景。

## 7. 功能需求

- [ ] 联系表单与自动回复
- [ ] WhatsApp / 电话快捷联系
- [ ] Google Map
- [ ] 案例筛选
- [ ] 博客 / 资源下载
- [ ] 多语言
- [ ] CMS 后台
- [ ] Analytics 与转化追踪
- [ ] 其他：[功能]

请区分必需功能与可选功能，并说明每项功能的用户价值、实施注意事项与优先级。

## 8. SEO建议

请提供：

- 核心关键词、长尾关键词与搜索意图
- 网站 URL、标题标签与 Meta Description 规划
- 页面级 H1/H2 内容方向
- 本地 SEO 或行业 SEO 建议
- 内容主题集群与博客选题
- 图片、内链、结构化数据与技术 SEO 建议
- 转化与 SEO 兼顾的 CTA 策略

请避免关键词堆砌，并优先提供符合真实客户搜索行为的建议。

## 9. 输出要求

请按以下顺序输出：

1. 项目定位与核心策略
2. 主要用户画像与用户旅程
3. Sitemap 与页面功能说明
4. 首页线框级内容结构
5. 各页面内容模块建议
6. 设计系统与配色方案
7. 功能优先级
8. SEO 关键词与内容计划
9. CTA、转化路径与 KPI 建议
10. 需要客户补充确认的问题

使用专业、清晰、可执行的中文；不要直接开发网站或输出代码。
