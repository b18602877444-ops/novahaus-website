- 个人姓名 / 品牌名：[姓名或品牌名]

- 核心服务：[咨询、顾问、课程、演讲等]
- 工作经历与成就：[经历、证书、媒体报道]

- 目标市场：[地区、语言、行业]
- 现有平台：[社交媒体、公众号、播客或作品集链接]

请总结个人定位、专业差异化、可信度来源以及网站应承担的品牌角色。

## 2. 目标客户

- 主要受众：[客户类型]
- 行业 / 职位：[画像]
- 年龄、地区与预算：[画像]
- 典型需求：[需求]
- 当前痛点：[痛点]

## 3. 网站目标

- 首要目标：[获取咨询 / 个人影响力 / 销售课程 / 演讲合作]
- 核心转化动作：[预约通话 / 留资 / 购买 / 订阅]

- 成功指标：[指标]

## 4. 网站结构

请规划以下页面及必要的扩展页面：

- 首页
- 关于我
- 专业服务
- 作品 / 案例 / 成果
- 内容中心 / 博客
- 课程 / 产品

请说明每页的叙事目标、内容模块、信任证明、CTA 与导航逻辑，并规划个人故事与专业成果的平衡。

## 5. 设计风格

请提供 2–3 套符合个人定位的配色方案，并列出主色、辅助色、强调色、背景色及 HEX 色值。说明每套方案传达的性格、适用场景、文字对比度与 CTA 使用方式。
