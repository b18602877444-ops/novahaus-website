# NOVAHAUS v1.0 Release Notes

## Release scope

This release publishes the approved public-facing positioning and conversion updates for NOVAHAUS:

- Brand Positioning Refresh
- China-to-Global positioning
- Sales Conversion content alignment
- Public Delivery System page
- Current commercial knowledge synchronisation required by the production application

## Public experience

- NOVAHAUS is presented as a coordinated Growth Operations Team.
- Web3 remains the deepest current focus.
- China-to-Global and Founder / Personal Brand audiences remain visible.
- The customer journey leads from context and solutions to delivery, investment and a Strategy Call.
- `/delivery-process/` explains the six-stage business delivery model.
- No guaranteed results, fabricated client claims or unverified credentials are introduced.

## Release boundaries

Internal operating manuals, sales documents, media assets, video-production files, experiments and temporary previews are not part of the public release commit.

## Validation

- Production build required before release commit.
- Desktop and mobile routes require verification after deployment.
- Vercel deployment must be confirmed from `origin/main`.
